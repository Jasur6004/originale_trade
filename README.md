# Telegram Бот для торговых сигналов

Бот для отправки торговых сигналов на основе технического анализа валютных пар.

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка конфигурации

Откройте файл `config.py` и настройте следующие параметры:

- `BOT_TOKEN` - токен вашего бота от @BotFather
- `PARTNER_LINK` - партнерская ссылка для регистрации
- `ADMIN_USERNAME` - ваш Telegram username (без @)
- `ACCESS_CODE` - секретный код доступа для активации

### 3. Запуск бота

```bash
python main.py
```

## 📋 Функционал

- ✅ Система регистрации и активации по коду доступа
- ✅ Главное меню с основными функциями
- ✅ Получение сигналов по 10 основным валютным парам
- ✅ OTC сигналы с рандомизацией (80-85% выигрыш)
- ✅ Реальный технический анализ через tradingview-ta
- ✅ Раздел обучения
- ✅ Поддержка пользователей

## 🔧 Структура проекта

```
trading_bot/
├── main.py              # Главный файл запуска бота
├── config.py            # Файл конфигурации
├── database.py          # Работа с базой данных SQLite
├── handlers.py          # Обработчики команд и callback-ов
├── trading_analysis.py  # Модуль технического анализа
├── requirements.txt     # Зависимости проекта
└── trading_bot.db       # База данных SQLite (создается автоматически)
```

## 📝 Примечания

- База данных SQLite создается автоматически при первом запуске
- Для получения реальных сигналов используется библиотека tradingview-ta
- OTC пары используют рандомизацию с настраиваемой вероятностью выигрыша
- Все настройки можно изменить в файле `config.py`
